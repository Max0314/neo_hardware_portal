# Task 010 - 宜搭物料库去重与单目标同步

## 背景

宜搭中的阻容感表单名称带有 `(C)`、`(R)`、`(L)`、`(FB)`、`(ECA)` 类型后缀。
硬件门户为兼容旧的无后缀物料库，在新旧名称同时存在时会把同一份宜搭数据写入两个库，
造成物料库重复、汇总数据重复和历史版本重复增长。

## 范围

- 同一张宜搭表单每次同步只能写入一个物料库。
- 新名称存在时优先写入与宜搭标题一致的物料库。
- 仅旧名称存在时继续兼容旧库，但不得同时创建或更新第二个库。
- 为同步表记录宜搭表单 UUID，降低表单改名后重复建库的风险。
- 内容未变化的定时同步不得重复生成历史版本。
- 生产数据清理前必须备份；合并旧库独有历史后再删除无后缀重复库。
- 恢复误删的 `0805电阻(R)`，最终物料库数量与宜搭同步源一致。

## 验收标准

- 宜搭同步源 72 个，门户物料库 72 个。
- 去除类型后缀后的重复分组为 0。
- 当前表内容与宜搭实际投影数据一致。
- 本次事务删除的旧无后缀库，其独有历史已迁入对应保留库。
- 在本次事务前已由人工删除的旧库，可通过已封存的 MySQL binlog 追溯。
- `0805电阻(R)` 恢复为宜搭当前的 112 条物料。
- 重复库没有残留用户权限引用。
- 回归测试覆盖“新旧库同时存在时只更新宜搭标题对应库”。

## 回滚

- 清理前导出 `material_db_libraries`、`material_db_audit` 和用户物料库权限数据。
- 记录删除目标、保留目标及历史合并结果。
- 如验证失败，使用清理前备份恢复相关表。
