支持的Excel表头格式

系统将自动识别以下表头名称（不区分大小写）：

  • 编号 / ID / No
  • 类别 / Category / 类型
  • 检查项 / Item / 项目
  • 问题级别 / Level / 优先级
  • 备注 / Notes / 说明

提示：支持合并单元格，系统会自动展开合并单元格并分配正确的值

使用说明

  1. 点击"导入Excel文件"按钮上传您的硬件检查清单Excel文件
  2. 系统支持表头：编号, 类别, 检查项, 问题级别, 备注（不区分大小写）
  3. 系统自动处理合并单元格，展开并分配正确的值到每一行
  4. 点击行末尾的"已完成/未完成"按钮切换状态
  5. 使用"添加检查项"按钮手动添加新的检查项目
  6. 使用"导出Excel"按钮导出包含状态信息的Excel文件
  7. 使用"导出PDF"按钮导出完整的PDF报告
  8. 使用"重置"按钮清除所有数据并重新开始

提示： 如果您没有Excel模板，可以 点击此处下载示例模板，然后根据您的需求修改内容。
